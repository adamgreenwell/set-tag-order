# Getting Started With Set Tag Order

## Requirements

- WordPress 6.3 or newer. Tested up to WordPress 7.1.
- PHP 7.4 or newer.

## Installation

1. In your admin panel, go to **Plugins → Add New**.
2. Search for **Set Tag Order**, or click **Upload Plugin** and choose the plugin `.zip`.
3. Click **Install Now**, then **Activate**.

Set Tag Order is available from the [WordPress.org plugin directory](https://wordpress.org/plugins/set-tag-order/).

## First Configuration Pass

Go to **Settings → Set Tag Order**. There is also a **Settings** link on the plugin's row on the Plugins screen.

1. Set the tag separator to use between tags on the front end. Leave it empty for no separator.
2. Add any CSS classes your theme should apply to tag links. Separate multiple classes with spaces. The field is validated as CSS class names rather than free text.
3. Save.

## Setting Your First Tag Order

1. Edit a post that already has several tags.
2. Find the Set Tag Order controls in the editor.
3. Put the tags in the order you want, by dragging or with the keyboard.
4. Update the post and view it on the front end to confirm the order.

See [Usage](usage.md) for how each editor behaves.
