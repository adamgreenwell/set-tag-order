# Set Tag Order Documentation

Set Tag Order lets editors choose the order post tags appear in, instead of accepting WordPress's default alphabetical listing. It works in both the Block Editor and the Classic Editor, and gives themes control over the separator and CSS classes used for tag output.

## What It Does

- **Custom tag order** — drag, or use the keyboard, to put tags in the order you want, per post.
- **Sort A-Z** — one control to fall back to alphabetical in either editor.
- **Custom separator** — choose the character between tags, or none at all.
- **Custom CSS classes** — add classes to tag links so your theme can style them.
- **Both editors** — the same ordering behaviour in the Block Editor and the Classic Editor.
- **Accessible** — keyboard reordering, labelled controls, and screen reader announcements.
- **Translatable** — a translation template ships in `languages/`.
- **Filters for developers** — `settagord_ordered_tags`, `settagord_separator`, and `settagord_link_classes`.

Settings live under **Settings → Set Tag Order**.
